# Meme audio

Nine short meme sound clips in MP3 format: MPEG-2 Layer III, 48 kbps constant
bitrate, 24 kHz, stereo. `validation.json` records file hashes and encoding details.

Conversion: FFmpeg, `-map 0:a:0 -vn -map_metadata -1 -ac 2 -codec:a libmp3lame
-b:a 48k -ar 24000 -write_xing 0`. Original recordings are third-party audio;
conversion does not claim authorship or ownership of the sounds.
